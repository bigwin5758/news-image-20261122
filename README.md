One image summing up 22 November 2026: 35 stories, 6 regions, every one dated Sunday 22 November 2026.

Built for the [make.fun bounty](https://make.fun/bounty/news-image-20261122) — the program (`main.py`, Python 3.13 stdlib only) draws the whole page in code: a clean stroke font, hero illustrations, a world map with numbered pins, a by-the-numbers strip, and a DATE CHECK box naming what was left out as other days' news.
